# Medical Policy MP-ORTHO-014: Knee Arthroscopy

Synthetic payer policy for testing.

## Coverage Criteria for Partial Meniscectomy

Arthroscopic partial meniscectomy (CPT 29880 or 29881) is considered medically necessary when ALL of the following are documented: mechanical symptoms such as locking, catching or giving way; a meniscal tear confirmed on MRI or by examination; and failure of at least 4 weeks of conservative therapy, including physical therapy or activity modification.

## Exclusions

Arthroscopic debridement or lavage for primary osteoarthritis of the knee is not medically necessary. Partial meniscectomy is not covered when imaging shows advanced osteoarthritis, defined as Kellgren-Lawrence grade 3 or 4, unless the member has true mechanical locking.

## Documentation Requirements

Reviewers must find the operative note, the MRI report, and records of conservative therapy with dates. Claims missing the operative note should be pended for records, not denied.

## Post-Payment Review Outcome Codes

Use outcome code SUP when documentation supports the billed service. Use outcome code NSUP when documentation does not support medical necessity. Use outcome code PEND when records are missing.
